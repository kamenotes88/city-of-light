# Help make one project easier to resume

Try one project in City of Light, save your world, then return to it later.
A short account of what worked or blocked you is enough. Copy the form below
into [GitHub Issues](https://github.com/kamenotes88/city-of-light/issues).
Feedback is optional; the preview collects no automatic usage telemetry.

Do not share passwords, tokens, private chat transcripts, customer data, full
backups or private project files. Use a fictional project name and redact errors.
A screenshot is optional and should show only what you can share publicly.
For a vulnerability, use [SECURITY.md](SECURITY.md) instead.

## Short form

```text
Version:
Assistant / OS / browser:
Interface language (optional):
Did your own world open? Yes / No / Not tried
Was one next step clear? Yes / No — optional short example:
Did you return in a later work session? Yes / No / Not yet
Did this avoid one repeated search or action? No / Not sure / Yes — which:
First confusing or failed step (optional):
One improvement you would use (optional):
One specific future paid operation you would value, and why (optional):
```

“Not yet” is useful. Report elapsed time only if measured. A request for a future
feature is not a purchase commitment. Stars, downloads, registrations and using
a world are different outcomes.

English and Russian are built in. Other languages use a complete data-only
translation pack prepared by your assistant. Package checks are separate from
translation and visual quality. Version 0.11.0 passed local package checks.
Automated anonymous HTTPS installation and repeat preservation also passed on
the maintainer's computer. Independent user installation, native assistant skill
discovery and other-language quality remain unverified. Please report your
observed version and experience rather than assuming another person's result.

## По-русски

Достаточно версии, среды и коротких ответов: открылся ли свой мир; понятен ли
следующий шаг; вернулись ли вы позже; удалось ли избежать конкретного повторного
поиска или действия. Если не пробовали или ещё не возвращались, так и напишите.
Личные файлы, переписки и пароли не нужны. Отзывы — в GitHub Issues; детали
уязвимости отправляйте только через проверенный приватный канал из SECURITY.md.
